## 4 — Tests Proxy → Analyseur (point critique)

L'Analyseur expose **deux** ports gRPC :
- `5002` = mTLS (Auditeur)
- `5012` = plain + header `X-Agent-Token` (Proxy)

Le `.deb` proxy-analyseur est configuré sur `ANALYSEUR_PORT=5002` avec mTLS — **incompatible** avec le serveur plain. Vérifie les deux cas :

### 4.1 Test correct — Proxy → Analyseur port **5012**

```bash
grpcurl -plaintext \
  -H "x-agent-token: $TOKEN" \
  -d '{
    "srcip":"192.168.123.50",
    "dstip":"8.8.8.8",
    "protocol":"TCP",
    "port":"443",
    "vm_id":"9101",
    "timestamp": 1710000000.0
  }' \
  $EMIR:5012 analyseur.AgentAnalyseur/EnvoyerLog
```

**Attendu :** `"statut":"ok"` ou détail d'anomalie. Pas `UNAUTHENTICATED`.

Si `UNAUTHENTICATED` → le token dans `/opt/gandal/proxy_token` du pod analyseur ne correspond pas à `$TOKEN`. Vérifie :

```bash
kubectl exec -n gandal deploy/agent-analyseur -- cat /opt/gandal/proxy_token 2>/dev/null || \
kubectl logs -n gandal deploy/agent-analyseur | grep -i token
```

### 4.2 Test actuel du .deb — port **5002** (doit échouer si mal configuré)

```bash
grpcurl -cacert $CERTS/ca.crt \
  -cert $CERTS/simulateur.crt -key $CERTS/simulateur.key \
  -d '{"srcip":"192.168.123.50","dstip":"8.8.8.8","protocol":"TCP","port":"443","vm_id":"9101","timestamp":1710000000.0}' \
  $EMIR:5002 analyseur.AgentAnalyseur/EnvoyerLog
```

**Attendu si proxy.env corrigé :** OK avec cert `simulateur`.  
**Si échec :** corrige sur la VM :

```bash
# Sur la VM proxy
```

### 6.2 `VerifierSante` depuis Kali (cert decideur → proxy VM)

Sur Kali, crée un script Python minimal (stubs déjà dans le .deb sur la VM). Plus simple : **depuis la VM** :

```bash
ssh root@$VM 'python3 - << "PY"
import grpc, controleur_pb2, controleur_pb2_grpc, os

PKI = "/etc/gandal-proxy/pki"
with open(f"{PKI}/ca/ca.crt","rb") as f: ca = f.read()
with open(f"{PKI}/simulateur/simulateur.crt","rb") as f: crt = f.read()
with open(f"{PKI}/simulateur/simulateur.key","rb") as f: key = f.read()

creds = grpc.ssl_channel_credentials(ca, key, crt)
ch = grpc.secure_channel("127.0.0.1:5007", creds)
stub = controleur_pb2_grpc.ControleProxyStub(ch)
rep = stub.VerifierSante(controleur_pb2.RequeteSante())
print("status:", rep.status, "agent:", rep.agent, "isolee:", rep.isolee)
PY'
```

**Attendu :** `status: ok`, `isolee: False`.

### 6.3 `IsolerVM` (test réel — attention, coupe le réseau VM)

```bash
ssh root@$VM 'python3 - << "PY"
import grpc, controleur_pb2, controleur_pb2_grpc

PKI = "/etc/gandal-proxy/pki"
with open(f"{PKI}/ca/ca.crt","rb") as f: ca = f.read()
with open(f"{PKI}/simulateur/simulateur.crt","rb") as f: crt = f.read()
with open(f"{PKI}/simulateur/simulateur.key","rb") as f: key = f.read()

creds = grpc.ssl_channel_credentials(ca, key, crt)

    alert_id="test-001", vm_id="", raison="test GANDAL"))
```

**Attendu :** `ok` + message isolation (si Proxmox configuré). Sinon `erreur` + `API Proxmox non configurée` — normal en lab sans token Proxmox.

## 10 — Script de test automatique (Kali)

Enregistre et lance :

```bash
cat > /tmp/gandal-test-all.sh << 'SCRIPT'
#!/usr/bin/env bash
set -uo pipefail
EMIR=${EMIR:-192.168.123.110}
FILTREUR=${FILTREUR:-192.168.123.200}
TOKEN=${TOKEN:-ENSPY-TOKEN-2026}
CERTS=${CERTS:-/tmp/gandal-certs}
PASS=0; FAIL=0

ok()  { echo "  ✅ $1"; PASS=$((PASS+1)); }
ko()  { echo "  ❌ $1"; FAIL=$((FAIL+1)); }

check_tcp() {
  nc -z -w2 "$1" "$2" 2>/dev/null && ok "TCP $1:$2" || ko "TCP $1:$2"
}
check_http() {
  code=$(curl -s -o /dev/null -w "%{http_code}" --max-time 5 "$1")
  [[ "$code" =~ ^2 ]] && ok "HTTP $1 → $code" || ko "HTTP $1 → $code"
}

echo "=== GANDAL TEST SUITE ==="
echo "--- Ports Emir ---"
for p in 5002 5012 5003 5013 5004 5014 5005 5006 5009 5016 8000; do
  check_tcp $EMIR $p
done
check_tcp $FILTREUR 5001

echo "--- HTTP ---"
check_http "http://$EMIR:5009/health"
check_http "http://$EMIR:5013/health"
check_http "http://$EMIR:5014/health"
check_http "http://$EMIR:8000/"

echo "--- gRPC ---"
grpcurl -cacert $CERTS/ca.crt -cert $CERTS/decideur.crt -key $CERTS/decideur.key \
  $EMIR:5004 agents.AgentChiffreur/GetHealth >/dev/null 2>&1 \
  && ok "Chiffreur GetHealth" || ko "Chiffreur GetHealth"

grpcurl -plaintext -H "x-agent-token: $TOKEN" \
  -d '{"srcip":"10.0.0.1","dstip":"8.8.8.8","protocol":"TCP","port":"443","vm_id":"test","timestamp":1710000000}' \
  $EMIR:5012 analyseur.AgentAnalyseur/EnvoyerLog >/dev/null 2>&1 \
  && ok "Proxy→Analyseur EnvoyerLog (5012)" || ko "Proxy→Analyseur EnvoyerLog (5012)"

grpcurl -cacert $CERTS/ca.crt -cert $CERTS/decideur.crt -key $CERTS/decideur.key \
  -H "x-agent-token: $TOKEN" $FILTREUR:5001 agents.AgentFiltreur/GetHealth >/dev/null 2>&1 \
  && ok "Filtreur GetHealth" || ko "Filtreur GetHealth"

echo ""
echo "Résultat : $PASS OK / $FAIL FAIL"
[[ $FAIL -eq 0 ]] && exit 0 || exit 1
SCRIPT
chmod +x /tmp/gandal-test-all.sh
/tmp/gandal-test-all.sh
```

## 11 — Tableau de diagnostic rapide

| Symptôme | Cause probable | Commande diagnostic |
|---|---|---|
| Proxy `UNAVAILABLE` sur 5002 | Mauvais port (doit être **5012**) | `grep ANALYSEUR_PORT /etc/gandal-proxy/proxy.env` |
| `UNAUTHENTICATED` sur 5012 | Token proxy incorrect | `kubectl exec ... cat /opt/gandal/proxy_token` |
| Filtreur `connection refused` | Service down ou mauvaise IP | `systemctl status agent-filtreur` |
| Chiffreur HTTP timeout | NodePort 5014 absent | `kubectl get svc svc-chiffreur -n gandal` |
| IsolerVM échoue | Proxmox token absent | `grep PROXMOX /etc/gandal-proxy/proxy.env` |
| .deb 404 | deb-server vide | `ls /opt/gandal-debs/` sur Emir |
| mTLS handshake fail | SAN cert incorrect | `openssl x509 -in $CERTS/decideur.crt -text \| grep DNS` |

## Point important à corriger avant les tests proxy

Sur chaque VM, le `proxy.env` doit avoir :

```bash
ANALYSEUR_HOST=192.168.123.110
ANALYSEUR_PORT=5012
```

Et l'Analyseur doit avoir le même token que les proxies dans `/opt/gandal/proxy_token` du pod.

Sans ça, le **Scénario A** échouera même si tout le reste fonctionne.

Si tu veux, je peux te générer un script `gandal-e2e-test.sh` complet à placer dans le repo, avec rapport JSON à la fin.
